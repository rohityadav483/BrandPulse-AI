# BrandPulse AI — Design System

Phase 0 visual contract for the clickable demo and later production screens.

## Principles

1. **Professional SaaS:** clear hierarchy, compact cards, evidence-first presentation.
2. **White and blue:** white page surfaces, blue primary actions, light-blue secondary surfaces, navy text, light gray-blue borders.
3. **Semantic colors only:** red/yellow/green are reserved for risk, warnings, success and confidence/status states.
4. **No dark mode:** the MVP is intentionally light-only.
5. **Numbers are contextual:** show sample sizes beside scores and signals whenever the API provides them.
6. **Evidence is traceable:** insights link to evidence and original source URLs.

## Tokens

| Token | Value | Use |
|---|---|---|
| Navy | `#0f2747` | Primary text/headings |
| Blue | `#2563eb` | Primary action/link |
| Light blue | `#eff6ff` | Secondary surfaces/badges |
| Border | `#dbe5f1` | Cards, inputs, separators |
| Page | `#f8fafc` | App background |
| White | `#ffffff` | Cards/navigation |

Semantic status colors use Tailwind semantic utilities and are not used decoratively.

## Layout

- Max content width: roughly `1200–1280px`.
- Desktop: two-column layouts for signal/evidence content where useful.
- Mobile: single-column stack; actions remain reachable without horizontal scrolling.
- Cards use rounded corners, thin borders and restrained shadows.

## Typography

- Page title: bold, high contrast, 30–48px depending on viewport.
- Section title: 16–20px semibold.
- Body: 14–16px with comfortable line height.
- Metric values: 24–36px bold.
- Metadata: 12–13px muted.

## Key interaction hierarchy

The visual emphasis is:

```text
Brand Health
    ↓
Emerging Signal
    ↓
Investigate
    ↓
Evidence
    ↓
Recommendation
```

The Emerging Signal card is the main decision point. Investigation findings must show citation counts and confidence context. Fallback-generated reports must visibly say `Generated by fallback`.

## Required states

The UI must have a design for:

- loading/skeleton
- empty/no signal
- low data
- partial results with warnings
- API error
- quota-low
- fallback-generated investigation

The golden fixture is the default development/demo state and must not spend external API credits.
